{%- comment -%} The S2S operational framework. Each stage is a row: the stage description on the left, the outputs it hands to the next stage on the right, with a connecting line running down the chain. Reads `stages` from _data/programme.yml. To add a stage, add a block there — nothing here needs changing. An output is either plain text: outputs: - Capability gap analysis or a link, written as a name and a url: outputs: - name: Need Assessment Survey url: https://forms.office.com/... A url containing "://" is treated as external and gets rel="noopener" and an arrow; anything else is treated as a path on this site and passed through relative_url so the baseurl is added. Built as an ordered list rather than an image, so it stays readable on a phone, in a screen reader, and with CSS disabled. On narrow screens the outputs box stacks underneath its stage. {%- endcomment -%} {%- assign stages = site.data.programme.stages -%}
